# CORNERED

등 뒤는 로프다. 브라우저에서 바로 하는 1인칭 3D 복싱.

**플레이: https://dinored960018.github.io/cornered/**

## 조작

키는 다섯 개만 씁니다. 앞으로는 저절로 걸어 들어가고, 훅과 어퍼는 상황에 따라 저절로 나갑니다.

| 동작 | A (WASD + J K L) | B (방향키 + Z X C) |
| --- | --- | --- |
| 피하기 | `A` `D` | `←` `→` |
| 숙이기 | `S` | `↓` |
| 가드 | `W` | `↑` |
| 왼손 / 오른손 | `J` `K` | `Z` `X` |
| 필살기 | `L` | `C` |

- 피하면서(또는 막 피하고) 치면 훅, 숙인 채 치면 어퍼.
- 곧게 오는 주먹은 좌우로, 훅은 숙여서, 몸통은 가드로 막습니다.
- 상대 주먹은 맞기 직전까지 내 머리를 따라옵니다. 끝까지 보고 움직여야 피합니다.

## 친구와 대전

메뉴의 "친구와 대전"을 누르면 초대 링크가 나옵니다. 친구가 그 링크로 들어오면 둘 다 복서를 고르고 바로 붙습니다. 서버 없이 브라우저끼리 직접 잇습니다 (연결 신호만 PeerJS 공용 서버를 씁니다). 방을 만든 쪽이 경기를 돌리므로, 방장이 창을 닫으면 경기가 끝납니다.

## 복서

인파이터, 아웃복서, 행운복서, 더티복서, 스위치복서, 사우스포, 탱크복서. 수치와 필살기는 `js/roster.js`에 있습니다.

## 개발

```
npm start         # http://localhost:7900
npm test          # 규칙 테스트
npm run balance   # 봇과 붙여 본 승률
node scripts/shots.mjs   # 장면 스크린샷
node scripts/play.mjs    # 실제 키 입력으로 한 판
node scripts/online.mjs  # 탭 두 개로 온라인 대전 확인
node scripts/jitter.mjs  # 상대 머리 떨림 측정
```

빌드 없는 ES 모듈입니다. 3D는 `vendor/`의 Three.js를 쓰고, 모델과 소리는 전부 코드로 만듭니다.
